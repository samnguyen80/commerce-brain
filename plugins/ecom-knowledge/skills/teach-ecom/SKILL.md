# Teach Ecom Brain

Read `../../knowledge/concepts/two-axis-taxonomy.md`, then the model card relevant to the requested topic.

## Method

1. Present one concrete merchant scenario.
2. Ask the learner for the fulfillment and channel coordinates. Wait for the answer.
3. Correct only the mistaken axis.
4. Ask which operating constraint appears first.
5. Reveal the card's economics, failure mode, and one practical job.

Teach one scenario at a time. Do not dump all 13 cards. Learning is complete when the learner can classify both axes and explain why the nearest confusing label is wrong.

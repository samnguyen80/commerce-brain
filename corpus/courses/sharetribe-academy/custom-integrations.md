# Custom marketplace integrations

## Connect your marketplace to any third-party application or custom backend

 

 Integration API, Events and SSO

## Develop complex integrations using Sharetribe&#x27;s Integration API, Events, and Single sign-on features.

 
 
 

 Integration API

 

### Get full API access to your data and build unique workflows

 - 

#### React to events in third-party applications
 Take automatic action in your marketplace when something happens elsewhere, such as a third-party online store, booking site, or a delivery platform. Update listing inventory, availability calendars, or order status.
 
 + 

#### Build your own admin and reporting tools
 Get data from your marketplace and process it the way you want. Create unique admin user interfaces or custom reports.
 
 + 

#### Run mass operations
 Update a large number of users and listings at once. Rank your listings by popularity and automatically update the order when things change. Create listings in bulk.
 
 
 

 
 

 Events

 Automatically react to events in your marketplace

 - 

#### Send data to third-party applications.
 Take action elsewhere when something happens in your marketplace. Update inventory in an online store. Update calendar availability in a booking site. Notify a delivery service about a new order.
 
 + 

#### Build automated asynchronous workflows
 React to new data and process resource-intensive tasks without slowing down the user experience. Notify customers when a listing that meets their criteria is posted. Update the popularity ranking of a listing when there&#x27;s a new booking. 
 
 
 

 
 

 Single sign-on

 Add any social login or third-party authentication method

 - 

#### Social logins
 Let users log in with social media credentials: Facebook, Google, Twitter, LinkedIn, or any other platform. Sharetribe has pre-built login integrations with Facebook and Google.
 
 + 

#### Other authentication methods
 Let users log in with a mobile number instead of email. Or use the credentials of any third-party app, even one you built yourself.

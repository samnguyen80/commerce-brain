# Marketplace management tools

## Run your business with world-class marketplace management tools

 

 
 
 
 
 
 
 
 

 User management

 

### Manage supplier and customer data

 - 

#### Search and filter users in the database
 Stay on top of user data. Search by name, email, or ID. Filter by multiple conditions or find information like which users have posted listings or who has an unverified email address.
 
 + 

#### Curate user data
 Edit user bios, names, emails, and custom user data directly in Console. Add operator-controlled information like verification or background check status.
 
 + 

#### Control user access
 Decide who gets access to your marketplace. Grant full access to all users at signup or approve users before giving them access to your marketplace or letting them publish listings and start transactions. Show listings and user profiles to visitors or limit access to them to logged-in users only.
 
 + 

#### Ban and delete bad actors
 Ban and delete users who engage in inappropriate behavior on your marketplace.
 
 + 

#### Send email to individual users via Console
 Reach out to your users by email. All user emails are easily accessible through Console.
 
 + 

#### Log in as a user
 Log in and take action on behalf of your users. See how the platform looks for users, troubleshoot issues, help users list on the platform, or offer a white-glove experience.
 
 + 

#### Export user data as CSV
 Export your user data at any time in a CSV file. Import the to other tools for further analysis.
 
 + 

#### Track referrals
 See which channel, referrer, or partner brought each user to your marketplace. Set up custom referral sources, track paid ads or influencer marketing, or set up an affiliate program.
 
 
 

 
 
 
 
 

 Listing management

 

### Curate listing data

 - 

#### Search and filter listings in the database
 See all listings in Console. Filter by multiple conditions such as listing state, listing author, listing type, and more. Easily discover pending actions.
 
 + 

#### Approve listings before publishing
 Preview and approve listings before they are published. Fix typos and contact providers to improve listings.
 
 + 

#### Edit listing data
 Edit listing names, descriptions, and custom field information in Console. Add operator-controlled information like verification, featured status, or ranking.
 
 + 

#### Close or remove listings
 Manage your supply. Close listings so that only you and the supplier can see them, or delete listings entirely. Download or delete the files a seller uploaded to a listing, even after it&#x27;s been purchased.
 
 + 

#### Export listing data as CSV
 Export your listing data at any time in a CSV file. Import data to other tools for further analysis.
 
 
 

 
 
 
 

 Transaction management

 

### Manage bookings, purchases, and conversations

 - 

#### Filter transactions in the database
 View transactions in Console. Filter transaction data by multiple conditions and discover actionable insights and growth issues.
 
 + 

#### Process payouts, cancellations, and refunds
 React to unexpected events. Manually process payouts when the automatic flow is disrupted. Cancel bookings and purchases. Issue refunds in dispute cases. 
 
 + 

#### Monitor conversations between users
 Read transaction conversations between suppliers and customers. Make sure your users respect your marketplace&#x27;s terms and conditions. Download files attached to listings or messages, and delete them everywhere at once or from just one transaction.
 
 + 

#### Export transaction data as CSV
 Export your transaction data at any time in a CSV file. Upload the file to other tools for further analysis.
 
 
 

 
 
 

 Review management

 

### Monitor and edit reviews

 - 

#### Find reviews in the database
 View all reviews in Console. Find the reviews a specific listing or user has received or look up reviews related to a particular transaction.
 
 + 

#### Add and edit review content
 Edit reviews after they’ve been published. Fix typos, remove identifying information, or edit them based on user requests. Add reviews that came in after the official review period, or include reviews to transactions that don&#x27;t have a default review flow.
 
 + 

#### Export review data as CSV
 Export your review data at any time in a CSV file at any time. Import data to other tools for further analysis.

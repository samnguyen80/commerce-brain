# What&#x27;s new in Sharetribe
 Sharetribe is constantly improving. Here you can find the latest updates. If you&#x27;re interested in knowing what we&#x27;re currently working on, check out our public roadmap.
 View roadmap 

 

## August 2026

 🚀 New in Developer Platform: Private file attachments
 Private file attachments are now available in the Marketplace and Integration APIs. Private files can only be accessed by an authenticated user or the marketplace operator.
 🛠 Improvements: 
 Reorder listing images (template release: v12.2.0 ): When creating a listing, users can now drag and drop the images they&#x27;ve uploaded into the order they want. 

 

## July 2026

 🚀 New in Sharetribe: Purchase digital files Template release: v12.0.0 
 Sharetribe’s newest transaction process, Digital download, is built for products that are delivered as a digital file. Sellers upload files to their listings, and buyers get access to them automatically after purchase. Everything happens and is stored in your Sharetribe marketplace. All files uploaded to a listing are held securely in Sharetribe-hosted storage and directly accessible through your marketplace and Console.
 
 🛠 Improvements: 
 
- Reorder listing images (template release: v12.2.0 ): When creating a listing, users can now drag and drop the images they&#x27;ve uploaded into the order they want. Took a while, but we got there! 
- Change the role of an organization member in Console: On the organization management page , organization owners can now change an operators&#x27; role to owner or vice versa as long as there&#x27;s always at least one owner. 

 

## June 2026

 🚀 New feature: Attach files to messages Template release: v11.2.0 
 Customers and providers can now attach files to transaction messages: up to 10 files per message, maximum 1 GB per file. Add support for transactions where files need to change hands. Let users share project assets, deliver completed digital work, and send images or documents to each other without leaving your platform.
 
 🚀 New third-party integration: Grow your marketplace through affiliates and referrals with Toppal 
 Run referral, affiliate, and influencer programs with Toppal, a service built specifically to work with Sharetribe’s referral source feature. Give partners unique affiliate links and see which partners drive sign-ups and revenue on your marketplace. Determine whether affiliates get a commission for each new user or completed transaction they bring to your platform.
 
 🚀 New feature: Referral sources Template release: v11.1.0 
 Set up referral sources in your user type settings to capture where new users came from. Use referral sources to attribute sign-ups to specific referrers in affiliate programs or track which users come from paid ad campaigns or influencer partnerships.
 
 🚀 New in Sharetribe Docs: AI assistant and MCP server 
 The Sharetribe Docs now has two new tools to make development easier: an AI assistant and a documentation MCP server. Ask the Docs AI a question and get an answer that&#x27;s pulled directly from the docs. The MCP server lets you connect Cursor, VS Code, Claude Code, and other code editors directly to our documentation.

 

## May 2026

 🚀 New feature:  Custom sorting options and search ranking Template release: v10.15.0 
 You can now choose which sorting options appear on your search page. Toggle the default options on or off and create custom sorting options based on numeric metadata fields. Use numeric metadata to create a fully custom search ranking order.
 🚀 New in Developer Platform:  Verify user email address via the Integration API
 It is now possible to build integrations that verify a user&#x27;s email address automatically. This API feature is only available for marketplaces that use their own SendGrid account for outgoing email.

 

## April 2026

 🚀 New feature:  Metadata fields Template release: v10.15.0 
 Add metadata to listings and profiles and use it to add trust signals, featured listing tags, custom search filters, unique sorting criteria, and more. Unlike regular, public listing and user fields, only you, the marketplace operator, can add or change metadata.
 
 🚀 New custom field type: Single-line text Template release: v11.0.0 Patch release: v11.0.1 Patch release: v11.0.2 
 There&#x27;s a new custom field type for user, listing, and transaction fields: single-line text. Add a single-line text field for a compact, short answers of up to 70 characters.

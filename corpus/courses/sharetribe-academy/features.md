## Users
 

### User sign-up with email verification
 Users sign up with email and determine their passwords. Each user needs to verify their email address. The platform automatically sends reminders to users who haven’t verified theirs.

 

### User sign-up through Google and Facebook
 Users can sign up with Google or Facebook and log back in at any time using the same social media account.

 

### User types
 With user types, you can differentiate between providers and customers. Create unique onboarding flows for different types of users and ask for specific information based on user type. Control what each user type sees in their account.

 

### Public user fields
 Determine the information you want to collect from your users during signup with custom user fields. Add dropdown selections, multiple-choice checkboxes, single-line text fields (for short answers), long text fields, and YouTube video embeds.

 

### Private user fields
 Collect sensitive or private information from users that only you and the user can see. Ask for info like company tax IDs, professional credentials, or demographic info for analytics—and keep confidential details private.

 

### Metadata user fields
 Add operator-controlled metadata to user profiles. Use metadata to add trust signals, featured listing tags, custom search filters, unique sorting criteria, and more. Unlike regular listing and user fields, only you, the marketplace operator, can add or change metadata.

 

### Public profiles for users
 Every user has a profile that includes information about them, ratings from other users to create trust, and more.

 

### Storefronts for suppliers
 Supplier profiles double as public storefronts that display their listings, reviews, and more.

 

### Referral sources
 Set up custom referral sources, track paid ads or influencer marketing, or set up an affiliate program. See which channel, referrer, or partner brought each user to your marketplace. 

 

## Listings
 

### List rentals, services, or products
 Users can post rental, service, or product listings on the platform through a streamlined listing creation form.

 

### Add listing images
 Add listing images to show what’s on offer. Choose the image aspect ratio that best aligns with what your marketplace offers. There&#x27;s no hard limit to how many images you can add per listing. Or create listings without images at all.

 

### Listing categories
 Help customers find what they&#x27;re looking for with listing categories. You can create up to three levels of categories and add category-specific listing fields to build dynamic listing creation and search experiences.

 

### Default listing fields
 All listings have a title, description, price, location, delivery options, availability, and stock, depending on the transaction type. You can turn off the description, location, and delivery options to support different kinds of listings.

 

### Public listing fields
 Determine the information you want to collect from your suppliers with custom listing fields. Add dropdown selections, checkboxes, number fields, single-line text fields (for short answers), long text fields, and YouTube video embeds.

 

### Metadata listing fields
 Create metadata listing fields that only you can set in Console. Mark listings as verified, control listing order in search results, tag listing for featured collection, or use metadata for internal operations without letting providers themselves touch those values.

 

## Availability and bookings
 

### Availability management
 Suppliers set and manage the availability of their listing on a weekly schedule.

 

### Hourly, daily, or nightly bookings
 Enable bookings by the day, night, or hour. Customers choose the start and end time of their booking.

 

### Fixed booking slots
 Let providers determine a fixed length for booking slots: 15 minutes, 30 minutes, 45 minutes—all the way up to 11 hours and 45 minutes. The customer makes chooses when their booking starts and it will last for as long as the provider determined.

 

### Price variations
 Let providers add several different pricing packages to a single listing—and manage all bookings in the same calendar to keep track of availability. Combine price variations with fixed booking slots, and the bookings vary in both length and price.

 

### One or multiple seats
 Listings on your marketplace can have one seat by default or you can let suppliers add multiple seats to each time slot.

 

### Availability exceptions
 Suppliers can easily control their schedule by adding day and hour-specific availability exceptions.

 

## Inventory management
 

### Multiple and one-item inventory
 Enable inventory for product listings. One-item stock is great for second-hand and unique items. Multiple-item inventory works for new products.

 

### Inventory editing
 Suppliers define how many items they have when creating a listing. The supplier can manually modify the inventory later.

 

### Automatic stock reduction
 Inventory reduces automatically when products are sold. When someone buys the last item, the listing closes until the supplier adds new inventory.

 

### Infinite stock
 Set stock to infinite to support selling digital goods and services. With infinite stock, providers never need to add or manage listing stock.

 

## Shipping and delivery
 

### Shipping and pickup as delivery options
 Suppliers can choose shipping, pick-up or both as delivery options for their products.

 

### Shipping fees
 Suppliers can determine shipping feesfor their products. They can also determine an additional fee if someone buys more than one item to account for shipping costs.

 

### Collect shipping fees during the purchase
 The shipping fee is added to the listing price at checkout and itemized on their own line.

 

## Search
 

### Search by keyword, location, and moving the map
 Make your primary search function location-based or keyword-based. Our versatile search experience works for both local and global marketplaces. 

 

### Add a search bar to your homepage
 Help customers find what they need with a beautiful multi-option search bar. You can now add a search bar with multiple options to any content page.

 

### View results on a map or a grid
 Choose your search page layout from a map-and-listings view for location-based marketplaces and listings in a grid list for other marketplace types.

 

### Filter by listing type
 Create unique search experiences based on the type of listing someone is looking for. Add a listing type filter on the search page or build entirely separate paths for different audiences.

 

### Filter by category
 Customers can filter by category and subcategory. You can also create category-specific filters that only appear when a customer chooses a specific category.

 

### Filter by availability
 Customers can filter listings by the date and time they’re looking to make a booking for.

 

### Filter by price, keyword, and custom filters
 Customers can filter listings by price or keyword and use filters to update search results instantly.

 

### Sort results by price, date, and keyword relevancy
 Customer can order results based on filters like price and keyword relevancy.

 

## Transactions
 

### Bookings
 Enable bookings by the day, night, or hour. The supplier determines their availability while creating a listing, and the customer books from a listing calendar.

 

### Purchases
 Enable product selling with single or multiple-item inventory. Inventory updates automatically when products are sold. Listings close when inventory runs out.

 

### Digital downloads
 Enable selling digital products like templates, fonts, or stock photos with a dedicated transaction process, where files are uploaded to the listing and delivered automatically after purchase.

 

### Free messaging
 Enable transactions without online payments for use cases like gifting, bartering, recruitment, and matching. Or use any currency, facilitate transactions without online payments, and let users make payments off platform.

 

### Price negotiation
 Build a marketplace where customers and suppliers can negotiate on the price. Providers give a quote to the customer. The provider and customer can message each other and the customer can counter the offer before accepting it.

 

### Reverse transaction flow
 Support transactions where the provider starts the transaction. In a reverse flow, customers list what they need. Providers make offers based on the customer’s request.

 

### Multiple transaction flows in one marketplace
 Allow multiple different transaction flows in your marketplace through different listing types. Configure up to 20 listing types without coding.

 

### Custom transaction fields
 When your customers and providers need to communicate complex requirements, asking them for the right information at the beginning of a transaction can make a huge difference. Use transaction fields to ask for the most relevant info in a structured way.

 

## Online payments
 

### Process online payments in 26 countries
 Through Stripe, Sharetribe automatically supports payments in 26 countries.

 

### Automated Know-Your-Customer process for suppliers
 Collect all the necessary information from your suppliers to send them their earnings from transactions.

 

### Automatic payments
 Once a transaction is over, the payment is sent to the supplier automatically. You do not need to send money manually.

 

### Collect a commission
 Split payments between the supplier and your marketplace. Charge a commission from your customers, providers, or both. Decide percentage and minimum commission rates in Console or charge a flat fee. Stripe automatically charges it on all transactions. 

 

### Delay payouts
 Stripe securely holds a customer&#x27;s payment until a transaction is over. The payment is sent to the supplier after a successful transaction has concluded.

 

### Store credit card details
 Customers can store credit card details for future purchases to streamline the buying process.

 

## Messaging and email notifications
 

### User messaging
 Allow customers and suppliers to message each other to ask questions and agree on details.

 

### File attachments
 Let users upload and download documents, images, and other files directly in the transaction message thread, up to 10 per message and and 1 GB per file.

 

### User inbox
 Each user has an inbox where they receive booking requests, notifications of accepted bookings, new messages from other users, and more. Users can filter the inbox by newest transaction and latest activity.

 

### Automatic email notifications
 Sharetribe has an automated email notification system for when things happen on your marketplace. No one will miss a new order or booking request. You can also decide to exclude specific built-in emails from your marketplace messaging.

 

## Reviews
 

### Two-sided reviews
 Build trust through two-sided reviews. Collect reviews from customers and suppliers automatically at the end of every paid transaction.

 

### Five-star ratings
 Collect one-to-five star ratings after each paid transaction. Star-ratings are an easy and fast way to evaluate different offerings. 

 

### Text reviews
 Collect a free text review after every paid transaction. Text reviews share more detail about the experience.

 

### Double-blind review process
 Reviews are published only after both parties have left them or the review period is over. Double-blind reviews prevent feedback extortion.

 

### Display reviews in profiles and listings
 The reviews a user has received appear on their listings and profiles. Build trust with visible testimonials.

 

### Add and edit reviews
 Add reviews manually in Console for any transaction where the review period has expired, where a user left their feedback in the private conversation, or where the marketplace uses free messaging without an online payment flow.

 Choose a listing thumbnail aspect ratio from square, portrait or landscape to fit your marketplace&#x27;s offering.

## Access control
 

### Make marketplace private
 Make your marketplace private and only show listings to users who are logged.

 

### User approval
 Enable user approval and review each user before publishing. Add an optional call to action for users to get approval, for example to pay a subscription fee.

 

### Restrict rights to view listings
 Enable "Restrict rights to view listings" on a private marketplace and users can only their own profile and listings. Add an optional call to action for users to get viewing rights.

 

### Restrict posting rights
 Enable "Restrict posting rights" and only users with explicit permission can post listings. You can add a call to action for users to get posting rights.

 

### Restrict transactions rights
 Enable "Restrict transactions rights" and only users with explicit permission can start transations. You can add a call to action for users to get transaction rights.

 

### Listing approval
 Enable listing approval and review each listing before publishing. Add an optional call to action for users to get their listing approved, for example to pay a listing fee.

 

### Onboarding mode
 Create a pre-launch onboarding mode: let users sign up and add listings, but not see content created by others. When you have enough listings, give users full access, launch your platform, and start facilitating transactions.

## Customizable data schema
 

### Store any data to your users, listings, and transactions
 Store customizable data schema in any common data type like string, number, or Boolean. Every user, listing, and transaction has its own data store. 

 

### Create hierarchical data structures
 Add data in subfields – and subfields of subfields – in a JSON format to listings, users, and transactions.

 

### Decide who sees data
 Public data is displayed to everyone in listings and user profiles. Protected data is revealed during a transaction between a supplier and a customer. Private data is only displayed to the user whose data it is. Metadata is public information that only the marketplace operator can edit. 

 

### Add search filters and sorting options for your custom data
 Tailor the search experience to match your unique data structure. Let your search engine know if the data type is a list, a number, or something else. Decide which parts of your data are discoverable in keyword search. Create your own sorting algorithm.

### Add actions: payments, bookings, reviews, notifications, data collection
 Build your ideal transaction flow out of different actions. Decide when payments, reviews, notifications, and data collection (and more) happen and what are next steps.

 

### Customizable pricing
 Build versatile pricing with add-ons, discounts, and coupons. Create compex commission structures and seasonal or dynamic pricing. Add support for taxes.

 B2B Wave Bulletin is our regular update that highlights recent product improvements and updates we’ve made to the B2B Wave cloud-based B2B eCommerce platform so you can easily stay up-to-date with what’s new.

### Admin Panel 

##### Filter by active categories in PDF catalog
 Admins will now see only active product categories to show in the PDF catalog.

##### Add extra field show option for product fields
 When extra product fields are created, there is now the option of whether the fields will be shown to customers or not.

##### Allow making all address fields required
 You can opt to make all address fields mandatory for customers.

##### Support reordering product (and product variant) images 
 We now support recording product and product variant images

### API 

##### Add extra fields to product API
 The product extra fields can now be shown and updated through the API

##### Allow setting option of values to orders with API
 You can set option of values to orders through the API

### Imports/Exports 

##### Update stock on import order .xlsx if inventory is enabled
 Admins can now import an order spreadsheet and change inventory accordingly (using the &#x27;product_quantity&#x27; parameter).

##### Extra fields added to customers will now be able to be exported and imported
 You can import/export extra fields added to customer

### Reports 

##### Total cost column in product sales reports and exports
 We’ve added a total cost column in the product sales report and report export.

### Integrations 

##### QuickBooks Online
 B2B Wave now connects to Quickbooks Online using OAuth 2.0.

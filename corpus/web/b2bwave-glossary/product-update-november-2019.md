 B2B Wave Bulletin is our regular update that highlights recent product improvements and updates we’ve made to the B2B Wave cloud-based B2B eCommerce platform so you can easily stay up-to-date with what’s new.

### Storefront 

##### Highlight inactive products in current order
 Inactive products in a customer&#x27;s shopping cart will now have a slightly red background to indicate they are inactive.

### Admin Panel 

##### Allow sales reps to change customer payment options
 Admins can now give sales reps the ability to view and change a customer&#x27;s payment options.

##### Add tracking info to email templates
 Shipment tracking numbers can now be added to email notifications.

##### Prevent spam registrations
 Admins now have the option of requiring new customers to use a captcha on signup to prevent spam registrations.

### Sales rep portal 

##### Order review and payment
 You can allow reviewing and paying of orders if submitted by sales rep

### Integrations 

##### Xero
 When contact details are updated in B2B Wave, the change is also reflected on Xero.

##### ShipStation
 Users can now choose whether or not orders should automatically be sent to ShipStation upon order submission.

##### Stripe SCA
 Stripe payments now implement “Secure Customer Authentication.”

### Imports/exports 

##### Customers import/export minimum order value
 The minimum order value can now be set using the customer import spreadsheet.

### API 

##### When changing order status from the API change_status method, allow sending of emails or not
 Admins can now choose whether or not automatic email updates should be sent when a &#x27;change_status&#x27; API request is made to change an order&#x27;s status.

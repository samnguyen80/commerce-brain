 B2B Wave Bulletin is our regular update that highlights recent product improvements and updates we’ve made to the B2B Wave cloud-based B2B eCommerce platform so you can easily stay up-to-date with what’s new.

### Imports/exports 

##### File import log
 Your file imports are now logged and saved. This allows you to review all your imports at any time, including when they were uploaded and whether or not they were successful.

### Admin panel 

##### Private admin fields on orders
 You can now add additional fields to an order to help you better manage them. These fields are private and will be visible only to admin users.

### Sales rep portal 

##### Sales reps can add new customers
 Sales reps now have the ability to add new customers or invite customers to your online storefront by email. Admin users can enable or disable this option for specific sales reps.

### API 

##### JSON response includes warehouse ID
 If you are using our Warehouse feature, your customers can now see a product’s full details, including warehouse ID.

##### “Allow to edit is_private” field
 Admin users now have the option to make a product visible only to select customers. When used in conjunction with “customer_access,” this function will specify or restrict specific customers or privacy groups from accessing certain products.

### Payments 

##### Currencies without decimals now supported
 B2B Wave now supports more currencies! Currencies that don’t use decimals (such as JPY, Japanese Yen) are also now available to specify within your online portal and will appear on your storefront.

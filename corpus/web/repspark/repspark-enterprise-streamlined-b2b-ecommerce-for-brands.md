###### How is RepSpark priced for enterprise customers?

 
 
 
 

 
 
 

 
 

 
 RepSpark operates on a predictable annual subscription model. Pricing is determined by the number of internal users (such as sales representatives, customer service, operations, and management). There are no transaction-based fees or percentage-based charges on Gross Merchandise Volume (GMV), so costs remain stable as your wholesale volume grows. Retail partners have unlimited access to the platform without additional per-customer licensing fees. The subscription includes core platform features and dedicated support. For a custom quote, contact the RepSpark sales team directly. Note: Detailed pricing figures are not publicly documented; request a quote for specifics.

Note: Some advanced features may require specific plan levels or integrations; ask sales for details.

 Yes, RepSpark provides a RESTful API using JSON for data exchange. The API supports integration with ERP systems, payment gateways, and other business systems. Developers can access detailed API documentation, including endpoints, authentication, and usage examples, at the RepSpark developer portal. ###### What security and compliance certifications does RepSpark hold?

 
 
 
 

 
 
 

 
 

 
 RepSpark is SOC 2 Type II certified, ensuring controls for data security, availability, processing integrity, confidentiality, and privacy. The platform is also PCI DSS compliant for secure payment processing and aligns with GDPR for data protection in the European Economic Area. RepSpark does not currently list ISO 27001 or HIPAA compliance. For more details, visit the RepSpark Trust & Security Center. Note: If you require certifications not listed, contact RepSpark for clarification.
